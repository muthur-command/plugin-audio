# MCOS 音频插件（PulseAudio）

由 Supervisor 管理的 **音频** 插件容器，面向 **MCOS**（基于 **`ghcr.io/muthur-command/base`**；OCI 标签 **`io.mcio.*`**）。

在适用场景下保留上游 ALSA 声卡配置；版权见 **LICENSE**。

## 运维

若监管栈仍提供相同 CLI，**`ha audio`** 系列命令通常仍可用于查看与控制；具体以 MCOS / Supervisor 文档为准。
