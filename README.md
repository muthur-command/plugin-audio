# MCOS audio plugin (PulseAudio)

中文文档: [`README.zh-CN.md`](./README.zh-CN.md)

Supervisor-managed **audio** add-on for **MCOS** (PulseAudio on **`ghcr.io/muthur-command/base`**; OCI labels **`io.mcio.*`**).

Upstream ALSA card configs are retained where applicable; see **LICENSE** for copyright.

## Operations

If your stack exposes the same Supervisor CLI, **`ha audio`** commands remain useful for inspection and control; see your MCOS / Supervisor documentation for exact behavior.
